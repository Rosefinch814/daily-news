## 目标

修复 `xhs_magnetize` 和 `xhs_note_title` 为满足字数限制而丢失“尚未生效状态、未来生效时间或关键触发条件”的问题；保持 T18 严格 AI 边界，不放宽事实校验，也不使用规则标题或原标题作为可发布回退。

## 产品行为

1. 未来状态、生效时间和关键触发条件属于受保护事实。原标题或摘要出现“计划 / 目标 / 预计 / 将 / 最早某日”等信息时，磁化标题不得让读者误解为当前已经发生。
2. 标题空间不足时，信息保留优先级为：主体 → 状态 / 生效时间 → 触发条件 → 核心动作 → 其他数字。
3. `xhs_magnetize.restrained` 或 `xhs_note_title` 首次未通过反漂移校验时，把原始输入、失败标题和具体错误交给对应 AI 任务做一次最小语义修正。
4. 修正稿必须重新通过同一套长度、数字、主体、状态、程度和情绪词校验；通过才继续出图，仍失败或 provider 不可用则按 T18 阻断整次导出。
5. “可”只表示能力或权限，不能单独视为“尚未生效”的未来语气；明确保留原文未来日期及其“最早 / 不早于”等限定时，可作为未来状态证据。
6. 首次生成和语义修正分别落日志，便于区分模型初稿、失败原因和最终采用稿。

## 验收标准

- 2026-07-29 的新闻“美国最大电网将在缺电时限供大型数据中心，最早2027年6月启动”不得通过不含未来状态或生效时间的封面标题或发布标题。
- 合法标题如“最早2027年6月起，PJM缺电时可限供数据中心”可通过校验。
- 首次克制版或发布标题因状态事实缺失被拒后，自动语义修正一次；修正通过则正常导出并保存修正日志。
- 自动修正仍不合格或调用失败时，整次导出失败且不留 PNG、caption、cards 或标题变体。
- 原有数字、主体、长度、程度、克制版情绪词校验继续生效。
- 封面状态保护只影响 v2 的 `xhs_magnetize`；发布标题保护适用于三种模板共有的 `xhs_note_title`，其他模板视觉和封面文案不变。
- 全套测试通过；只重跑小红书导出时不修改日报 issue、dist 或线上内容。

## 非目标

- 不取消 T18 严格模式。
- 不把“可”加入未来语气白名单后直接放行。
- 不重新生成日报正文。
- 不自动发布到小红书。
